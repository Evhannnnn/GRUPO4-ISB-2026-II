  # Bienvenido al repositorio del grupo 4

  ## Curso
  Introducción a Señales Biomédicas

  ## Visión general del proyecto
  En este repositorio se documentará el proyecto semestral del curso. El trabajo abarca todo el recorrido de una bioseñal: parte del diseño del sistema de adquisición y del acondicionamiento de la señal (EMG, ECG o EEG), continúa con la aplicación de técnicas de filtrado digital avanzado —transformada wavelet, filtros adaptativos e ICA— y culmina con la incorporación de modelos de Machine Learning y TinyML sobre las señales ya procesadas. El resultado esperado es un prototipo funcional operable desde una interfaz de usuario.
